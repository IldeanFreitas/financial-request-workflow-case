# Checklist de revisão do case

Use esta lista antes de promover o case para uma página de portfólio, currículo ou publicação profissional.

## Precisão

- [x] O status é apresentado como `Arquitetura documentada`.
- [x] O repositório não afirma conexão ativa com ERP ou uso em produção.
- [x] O contrato de dados separa validação estrutural da regra semântica de rateio.
- [x] Os cenários descrevem resultado esperado, não métricas não comprovadas.

## Segurança

- [x] Nenhuma marca, pessoa, URL, ambiente ou identificador corporativo foi incluído.
- [x] Não há pacote de aplicativo, solução, fluxo, captura de tela ou documento real.
- [x] O exemplo usa valores, centros de custo e pessoa de referência sintéticos.
- [x] Arquivos e extensões sensíveis são ignorados pelo Git.

## Publicação

- [x] Links internos foram validados.
- [x] O schema e o exemplo sintético foram validados localmente.
- [x] O card de portfólio deve declarar a limitação de escopo e apontar para este repositório.
