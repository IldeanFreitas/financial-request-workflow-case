# Narrativa para portfólio

## Contexto

Workflow de referência para organizar solicitações financeiras, com dados de cabeçalho, rateio, evidências e acompanhamento do processamento externo.

## Contribuição representada

Documentação da arquitetura pública, modelagem do contrato de solicitação, definição de estados e regras de validação para uma reconstrução demonstrativa.

## Limitações declaradas

O material publicado não inclui uma implementação corporativa, conexão com ERP, arquivos enviados por usuários, telas, exports de Power Platform ou resultados operacionais. Por isso, o case é classificado como **Arquitetura documentada**.
